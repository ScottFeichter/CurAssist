# .gitignore

This file tells Git which files and directories to exclude from version control. Anything matching a pattern here will not be tracked, committed, or pushed.

---

## Key Entries Explained

```
.DS_Store
```
macOS Finder metadata file. Created automatically when you open a folder in Finder. Has no project value.

```
dist/
```
Compiled TypeScript output. Regenerated by `npm run build` — no need to version it. Each environment compiles its own.

```
logs
*.log
```
Runtime log files generated by Winston. These are environment-specific and can be large. The `logs/` directory structure is created at runtime.

```
coverage
*.lcov
```
Test coverage reports generated by `npm run test:coverage`. Regenerated on demand.

```
node_modules/
```
All installed NPM packages. Regenerated by `npm install` from `package-lock.json`. Would massively bloat the repo.

```
.env
.env/.env.development
.env/.env.production
.env/.env.testing
.env/.env.example
```
Environment variable files containing secrets (database credentials, API keys). **Never commit secrets to Git.** The `.env.example` is also listed here but ideally should be tracked as a template — this is a minor oversight.

```
docs/typedocs/
```
Generated TypeDoc HTML documentation. Regenerated by `npm run docs`. Large and changes with every build.

---

## Pattern Syntax

- `*.log` — matches any file ending in `.log` in any directory
- `dist/` — matches the `dist` directory and everything inside it
- `!pattern` — negates a previous pattern (not used here but available)
- `**/` — matches any number of nested directories
