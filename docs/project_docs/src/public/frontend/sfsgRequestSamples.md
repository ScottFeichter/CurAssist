# src/public/frontend/sfsgRequestSamples/

This directory contains captured request/response samples from the SF Service Guide API. These serve as reference documentation for the exact payloads SFSG expects and returns.

## Files

| File | Description |
|------|-------------|
| `newOrgReq.md` | Sample POST /api/resources request and response (create org) |
| `serviceReq.md` | Sample POST /api/resources/:id/services request and response |
| `updateOrgReq.md` | Sample POST /api/resources/:id/change_requests request and response |
| `getOrg.md` | Sample GET /api/v2/resources/:id response |
| `getOrgKai.md` | Another GET org sample (different org) |
| `deleteServiceReq.md` | Sample DELETE /api/services/:id request and response |

These are documentation files — not executed by any code.
