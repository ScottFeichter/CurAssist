# src/public/frontend/styles.css

This is the main stylesheet for the frontend application. It styles:

- The three-panel layout (left sidebar, center iframe, right sidebar)
- Navigation controls (dropdowns, buttons, file counter)
- Sidebar resize handles and collapse/expand behavior
- Modal dialogs (move, copy, delete, submit, create bucket, import)
- Notification popups
- Drag-and-drop file upload area
- Button styles and hover states
- Responsive adjustments

The org template displayed inside the iframe has its own embedded styles (from the template components) — this file only styles the outer application shell.
