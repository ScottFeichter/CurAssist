# src/public/frontend/Images/

Static image assets for the frontend UI.

| File | Purpose |
|------|---------|
| `CAlogo.png` | CurAssist logo (full) |
| `CAlogo WhiteDotOnly.png` | CurAssist logo variant (white dot only) |
| `CAfav.png` | Favicon/small icon |

These are served as static files by Express and referenced in `index.html`.
